# Student Mathematics Performance Analysis

## Project Overview
This project explores student mathematics performance using statistical analysis and data visualisation. The analysis focuses on final mathematics grades, the relationship between first-period and final grades, and differences in performance based on previous class failures.

## Dataset Information
- **Dataset:** `student-mat.csv`
- **Number of records:** 395 students
- **Number of columns:** 33
- **Main variables:**
  - `G1` – First-period grade
  - `G2` – Second-period grade
  - `G3` – Final mathematics grade
  - `studytime` – Weekly study-time category
  - `failures` – Number of previous class failures

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Git and GitHub

## Data Analysis and Visualisations

Three statistical visualisations are included:

1. **Histogram:** Shows the distribution of final mathematics grades (G3).
2. **Scatter Plot:** Explores the relationship between first-period grades (G1) and final grades (G3).
3. **Box Plot:** Compares final mathematics grades across groups based on previous class failures.

## Key Findings
- The average final mathematics grade is approximately 10.42.
- The correlation between first-period and final grades is approximately 0.8015, indicating a strong positive relationship.
- Median final grades decrease across groups with increasing numbers of previous class failures.

## Repository Contents
- `statistics_trends_report.pdf` – Two-page statistical analysis report.
- `student_performance_analysis_improved.ipynb` – Python notebook containing the analysis and visualisations.
- `student-mat.csv` – Dataset used for the analysis.

1. Download the repository files.
